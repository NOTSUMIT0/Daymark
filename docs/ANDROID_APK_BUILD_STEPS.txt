================================================================================
          DAYMARK (YOURDAILYDEED) — ANDROID APK BUILD STEP-BY-STEP GUIDE
================================================================================

PROJECT LOCATION:
  Root Directory:    k:\Work\YourDailyDEED
  Android Directory: k:\Work\YourDailyDEED\android

--------------------------------------------------------------------------------
STEP 1: OPEN THE ANDROID PROJECT IN ANDROID STUDIO / IDE
--------------------------------------------------------------------------------
Option A (Terminal Command):
  1. Open terminal inside k:\Work\YourDailyDEED
  2. Run the command:
     npx cap open android

Option B (Manual Open in IDE / Android Studio):
  1. Open Android Studio / IntelliJ IDE.
  2. Click "File" -> "Open...".
  3. Select the folder: k:\Work\YourDailyDEED\android
  4. Click "OK" to load the Android project.

--------------------------------------------------------------------------------
STEP 2: SET JAVA JDK 17+ (REQUIRED FOR ANDROID GRADLE)
--------------------------------------------------------------------------------
  1. In Android Studio top menu, click "File" -> "Project Structure..." (Shortcut: Ctrl + Alt + Shift + S).
  2. In the left sidebar, click "SDK Location" or "Gradle".
  3. Look for "Gradle JDK".
  4. Set "Gradle JDK" to "Embedded JDK" or "Java 17" / "Java 21" (Do NOT use Java 8).
  5. Click "Apply", then click "OK".

--------------------------------------------------------------------------------
STEP 3: GENERATE THE ANDROID APK
--------------------------------------------------------------------------------
  1. In the top menu bar of Android Studio / IDE, click on "Build".
  2. Hover over "Build Bundle(s) / APK(s)".
  3. Click on "Build APK(s)".
  4. Gradle will compile the project (takes ~1 to 2 minutes).

--------------------------------------------------------------------------------
STEP 4: EXACT FILE LOCATION OF THE GENERATED APK
--------------------------------------------------------------------------------
When compilation completes, Android Studio shows a pop-up in the bottom right:
  "APK(s) generated successfully for 1 module. locate"

Click "locate" OR manually open Windows File Explorer to this exact path:

  k:\Work\YourDailyDEED\android\app\build\outputs\apk\debug\app-debug.apk

--------------------------------------------------------------------------------
STEP 5: INSTALL ON MOBILE PHONE
--------------------------------------------------------------------------------
  1. Copy "app-debug.apk" to your Android mobile phone (via USB cable, Google Drive, Bluetooth, or Email).
  2. On your Android phone, open "Files" or "My Files" app.
  3. Tap on "app-debug.apk".
  4. Allow "Install from unknown sources" if prompted by Android.
  5. Tap "Install" and open your new Daymark app!
